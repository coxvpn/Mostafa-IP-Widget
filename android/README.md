# MyIP Widget - Android

Home-screen widget (and small app) that shows your public IP address, country flag,
city and provider. Tap the widget to refresh. Android 8.0 or newer.

Build: run the "Build Android app" workflow on GitHub (Actions tab), then download
the `MyIPWidget-Android` artifact. Android refreshes widgets by itself about every
30 minutes; tapping the widget refreshes it immediately.
