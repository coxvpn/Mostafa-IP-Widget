## فارسی

**Mostafa-IP-Widget** یک ابزار کوچک برای ویندوز و اندروید است که آی‌پی عمومی، کشور (با پرچم) و ارائه‌دهنده‌ی اینترنت شما را همیشه جلوی چشم نگه می‌دارد. با فیلترشکن یا تغییر شبکه، پرچم خودکار عوض می‌شود.

### امکانات

- نمایش آی‌پی عمومی، کشور، شهر و ارائه‌دهنده‌ی اینترنت
- پرچم کشور روی آیکون کنار ساعت (ویندوز) و روی ویجت صفحه‌ی اصلی (اندروید)
- نمایش دمای هوا برای شهری که خودتان انتخاب می‌کنید
- ویندوز: سرعت لحظه‌ای دانلود و آپلود و حجم مصرف امروز، روی نوار کوچکی کنار ساعت
- اندروید: حجم مصرف امروز روی ویجت و دکمه‌ی تازه‌سازی
- هر بخش را می‌توانید جدا روشن یا خاموش کنید
- آیکون مخصوص حالت «بدون اینترنت»
- تغییر سریع پرچم هنگام عوض شدن شبکه یا فیلترشکن

### نصب

**ویندوز**
1. از بخش [Releases](../../releases) فایل `Mostafa-IP-Widget-Setup.exe` را دانلود و اجرا کنید.
2. روی آیکون کنار ساعت کلیک کنید تا پنجره‌ی کوچک باز شود؛ با راست‌کلیک گزینه‌ها را تنظیم کنید.

**اندروید**
1. از بخش [Releases](../../releases) فایل `Mostafa-IP-Widget.apk` را دانلود و نصب کنید (اگر لازم شد، نصب از منبع ناشناس را مجاز کنید).
2. روی صفحه‌ی اصلی نگه دارید و از بخش ویجت‌ها، ویجت را اضافه کنید.
3. برای نمایش حجم مصرف، در برنامه دکمه‌ی «اجازه‌ی دسترسی به آمار مصرف» را بزنید.

## English

**Mostafa-IP-Widget** is a small tool for Windows and Android that keeps your public IP, country (with flag) and internet provider always in view. The flag updates automatically when you switch network or turn a VPN on or off.

### Features

- Shows public IP, country, city and internet provider
- Country flag on the tray icon (Windows) and on the home-screen widget (Android)
- Temperature for a city you choose yourself
- Windows: live download / upload speed and today's data usage on a small bar next to the clock
- Android: today's data usage on the widget, plus a refresh button
- Every part can be switched on or off separately
- A dedicated icon for "no internet"
- Fast flag update when the network or VPN changes

### Install

**Windows**
1. Download and run `Mostafa-IP-Widget-Setup.exe` from [Releases](../../releases).
2. Click the tray icon to open the pop-up; right-click it to change the options.

**Android**
1. Download and install `Mostafa-IP-Widget.apk` from [Releases](../../releases) (allow installs from unknown sources if asked).
2. Long-press the home screen, open Widgets and add the widget.
3. To show data usage, tap "Allow usage access" in the app and grant the permission.

### A note on safety

The app is not digitally signed, so Chrome or Windows may show a warning when you download or run it. The project is open source and the code can be inspected here. On Windows, choose "More info" and then "Run anyway".
