## فارسی

**Mostafa MultiWidget** 

یک ابزار سبک برای ویندوز و اندروید است که آی‌پی عمومی، کشور (با پرچم) و ارائه‌دهنده‌ی اینترنت شما را همیشه جلوی چشم نگه می‌دارد. با روشن یا خاموش کردن فیلترشکن یا عوض شدن شبکه، پرچم خودکار عوض می‌شود.

### تازه‌ها (نسخه‌ی ۰٫۵٫۲ ویندوز)

- نوار کوچکی که **داخل خود نوار وظیفه** (کنار ساعت) می‌نشیند و دما، سرعت لحظه‌ای و حجم مصرف امروز را نشان می‌دهد
- رنگ نوار خودکار با رنگ نوار وظیفه یکی می‌شود
- هر بخش را جدا از منوی راست‌کلیک آیکون کنار ساعت روشن یا خاموش می‌کنید
- اصلاح مشکل ماندن پرچم قبلی بعد از چند ساعت استفاده
- تشخیص دقیق‌تر کشور هنگام استفاده از فیلترشکن

### امکانات

- نمایش آی‌پی عمومی، کشور، شهر و ارائه‌دهنده‌ی اینترنت
- پرچم کشور روی آیکون کنار ساعت (ویندوز) و روی ویجت صفحه‌ی اصلی (اندروید)
- دمای هوا برای شهری که خودتان انتخاب می‌کنید
- ویندوز: سرعت لحظه‌ای دانلود و آپلود و حجم مصرف امروز روی نوار وظیفه
- اندروید: دما و حجم مصرف امروز روی ویجت، به‌همراه دکمه‌ی تازه‌سازی
- آیکون مخصوص حالت «بدون اینترنت»
- تغییر سریع پرچم هنگام عوض شدن شبکه یا فیلترشکن

### نصب

**ویندوز**
1. از بخش [Releases](../../releases) فایل `Mostafa-IP-Widget-Setup.exe` را دانلود و اجرا کنید.
2. روی آیکون کنار ساعت راست‌کلیک کنید و گزینه‌ی «Build the bar into the taskbar» را بزنید تا نوار داخل نوار وظیفه بنشیند (فقط ویندوز ۱۰).
3. با «Choose city for weather...» شهر خود را برای دما انتخاب کنید.

**اندروید**
1. از بخش [Releases](../../releases) فایل `Mostafa-IP-Widget.apk` را دانلود و نصب کنید (در صورت نیاز نصب از منبع ناشناس را مجاز کنید).
2. روی صفحه‌ی اصلی نگه دارید و ویجت را از بخش ویجت‌ها اضافه کنید.
3. برای نمایش حجم مصرف، در برنامه «اجازه‌ی دسترسی به آمار مصرف» را بزنید.

### نکته‌ی ایمنی

این برنامه امضای دیجیتال ندارد؛ بنابراین کروم یا ویندوز ممکن است هنگام دانلود یا اجرا هشدار بدهند. برنامه متن‌باز است و کد آن همین‌جا قابل بررسی است. در ویندوز «More info» و سپس «Run anyway» را بزنید.

ساخته‌شده توسط **مصطفی ماندگاری**. این پروژه بر پایه‌ی [My-IP-Widget](https://github.com/B3H1Z/My-IP-Widget) ساخته شده است.

## English

**Mostafa-IP-Widget** is a lightweight tool for Windows and Android that keeps your public IP, country (with flag) and internet provider always in view. The flag updates automatically when you turn a VPN on or off or switch network.

### What's new (Windows 0.5.2)

- A small bar that sits **inside the taskbar itself** (next to the clock) and shows the temperature, live speed and today's data usage
- The bar automatically matches the taskbar colour
- Each part can be switched on or off from the tray icon's right-click menu
- Fixed the old flag staying on screen after several hours of use
- More accurate country detection when a VPN is in use

### Features

- Shows public IP, country, city and internet provider
- Country flag on the tray icon (Windows) and on the home-screen widget (Android)
- Temperature for a city you choose yourself
- Windows: live download / upload speed and today's data usage on the taskbar
- Android: temperature and today's data usage on the widget, plus a refresh button
- A dedicated icon for "no internet"
- Fast flag update when the network or VPN changes

### Install

**Windows**
1. Download and run `Mostafa-IP-Widget-Setup.exe` from [Releases](../../releases).
2. Right-click the tray icon and choose "Build the bar into the taskbar" to place the bar inside the taskbar (Windows 10 only).
3. Use "Choose city for weather..." to pick your city for the temperature.

**Android**
1. Download and install `Mostafa-IP-Widget.apk` from [Releases](../../releases) (allow installs from unknown sources if asked).
2. Long-press the home screen, open Widgets and add the widget.
3. To show data usage, tap "Allow usage access" in the app and grant the permission.

### A note on safety

The app is not digitally signed, so Chrome or Windows may show a warning when you download or run it. The project is open source and the code can be inspected here. On Windows, choose "More info" and then "Run anyway".
